PROJECT INFORMATION

About RETINA AI

An academic prototype for explainable diabetic retinopathy screening.

AI-Based Diabetic Retinopathy Screening

Diabetic retinopathy (DR) is an eye condition associated with diabetes that can affect the blood vessels in the retina. This project demonstrates an AI-assisted workflow for retinal image quality assessment, severity classification and model explainability.

Fundus image

A fundus image is a photograph of the interior surface of the eye, including the retina, optic disc and blood vessels, captured using retinal imaging equipment.

Why image quality matters

Blur, poor illumination, low contrast or incomplete retinal coverage can make image interpretation unreliable. Quality checks should happen before classification.

EfficientNet-B0

EfficientNet-B0 is a convolutional neural network architecture that balances model depth, width and image resolution. It can be adapted through transfer learning for five DR grades.

Grad-CAM

Gradient-weighted Class Activation Mapping creates a heatmap from model gradients to highlight image regions influential to a selected prediction.

Five DR severity categories

0 No DR1 Mild DR2 Moderate DR3 Severe DR4 Proliferative DR

Dataset reference: APTOS 2019 Blindness Detection. The dataset is not bundled into this website.

Developed as an academic mini-project. This application is an educational screening prototype and does not replace examination by a qualified ophthalmologist.
